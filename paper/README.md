# The paper

The source PDF is retained locally as `paper/w34034.pdf` but is not committed,
because it is a third-party working paper and the repository should remain
lightweight.

**Agrawal, A. K., Gans, J. S., & Goldfarb, A. (2025).** *The Economics of
Bicycles for the Mind*. NBER Working Paper No. 34034.

- [NBER paper page](https://www.nber.org/papers/w34034)
- [DOI: 10.3386/w34034](https://doi.org/10.3386/w34034)
- [Official PDF](https://www.nber.org/system/files/working_papers/w34034/w34034.pdf)

This is an unrefereed NBER working paper, not an arXiv paper.
